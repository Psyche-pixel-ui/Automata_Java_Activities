# Java Automata 

Welcome to the **Automata Java ** project! This repository contains two separate Java-based simulators demonstrating automata concepts:

  **DFA (Deterministic Finite Automaton)**
  **NFA (Non-Deterministic Finite Automaton)**

Each simulator is contained in its own folder with a dedicated `README.md` file and Java source code.


## Folder Structure

| Folder | Description | Link |
|--------|-------------|------|
| `DFA/` | Contains the DFA String Acceptance Checker project | (https://github.com/Psyche-pixel-ui/Automata_Java_Activities/tree/main/DFA) |
| `NFA/` | Contains the NFA String Acceptance Simulator project | (https://github.com/Psyche-pixel-ui/Automata_Java_Activities/tree/main/NFA) |


##  How to Run

1. Navigate into either folder (`DFA/` or `NFA/`).
2. Open a terminal or command prompt in that folder.
3. Compile the Java file(s):
   ```bash
   javac *.java
